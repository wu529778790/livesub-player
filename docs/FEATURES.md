# LiveSub-Player 功能清单

> 发版时 Release 描述的固定素材：先放完整功能清单，再放「本版本更新」。每次功能有增删改，同步更新本文件。

LiveSub-Player 是一款 AI 双语字幕视频播放器：播放本地视频，AI 实时识别语音生成字幕，并翻译成中文。

## 播放器（mpv 内核）

- 支持 MP4 / MKV / MOV / WebM / AVI / TS / FLV / WMV 等主流格式，拖入窗口或点击选择即可播放
- 硬件解码（macOS VideoToolbox），解码 CPU 大幅下降，不支持自动落回软解
- 无级倍速：0.1x ~ 3x，Shift+滚轮 / [ ] 快捷键 0.1 步进微调，预设倍速一键切换
- 进度条拖动 + 悬停时间预览、快进快退、音量滑杆
- 截图到桌面、双击全屏、播放中鼠标静止 2.5s 自动隐藏全部界面（沉浸模式）
- 按文件记住播放进度：同一视频再次打开自动续播（看完 95% 以上则重头播），启动不自动打开任何视频
- 欢迎页「最近播放」列表：点一下直接续播，文件已删除的自动隐藏；菜单栏「文件 → 打开最近使用」同步可用
- 换片/关片走 macOS 菜单栏（文件 → 打开 ⌘O / 关闭 ⌘W）或右键菜单，播放中也能操作
- 播放列表：打开（或拖入）文件夹，里面的视频排成列表，点选换片、播完自动连播下一集，列表播完回到欢迎页

## AI 实时字幕与翻译

- 语音识别本地运行（Whisper），边看边出字幕，内容不上传
- 识别结果落成本机「字幕库」：重开视频秒出全片字幕，快进/回看到看过的位置零等待，重复观看零算力
- 看片期间后台自动补全：识别在你看片的同时把整部片子补完，完成后任意快进都有字幕（补全低优先级运行，不抢播放和实时识别）
- 识别语言可固定（自动检测 / 中 / 英 / 日 / 韩）：看已知语种的片识别更快更准，选自动则跟随内容切换
- 识别档位可选：均衡（默认）/ 快速（低配电脑）
- 翻译双通道：在线翻译开箱即用（自动走系统代理）；本地翻译完全离线、无视内容限制（引擎 ~12MB + 模型 ~4.4GB 应用内一键下载）
- 翻译缓存跨启动有效（按源文本去重，磁盘持久化）：重开视频、重复台词零开销；离播放位置最近的台词优先翻译，seek 后译文跟上的永远是正在看的部分
- 双语 / 译文 / 原文三种字幕模式（1/2/3 快捷键），译文大字在上、原文小字在下
- 原文字幕永不被翻译状态吞掉：翻译生成前先显示原文，译文到位自动切换
- 识别进度始终可见：正在识别的时段、落后于播放时显示已处理位置
- 导出全片字幕为 SRT 文件（E 快捷键 / 右键菜单）：优先复用字幕库（识别过的秒出），缺的部分后台补齐（带进度百分比、可随时取消）；完成后选择保存位置，UTF-8 编码 Windows 播放器无乱码

## 模型管理

- 识别 / 翻译模型在应用内一键下载与删除，带进度显示
- 本地翻译二件套：翻译引擎（llama-server，~12MB）+ 翻译模型（混元 MT-7B，~4.4GB），队列串行下载、断点续传
- 首次使用有引导向导（带实时下载进度），可跳过先用在线翻译
- 下载完成自动就位：翻译可用性自动恢复，无需重启或手动切换

## 设置

- 设置页分四组：字幕 / 识别·翻译 / 播放 / 通用
- 字幕：字号三档（小/中/大）、位置三档（贴底/上移/更高）、默认字幕模式
- 播放：记住音量与倍速（下次启动沿用）、记住播放位置（同一视频再次打开自动续播，可关）
- 通用：自动检查更新（可关）、手动检查更新、当前版本号、一键打开日志文件夹（排查问题）、官网与 GitHub 项目入口

## 桌面级体验

- macOS 原生体验：系统红绿灯、应用菜单（⌘Q 退出）、拖拽打开文件（含文件夹 = 播放列表）
- 菜单栏命令中心（对齐 IINA/QuickTime 惯例）：文件（打开 ⌘O / 打开文件夹 ⇧⌘O / 打开最近使用 / 关闭 ⌘W / 播放列表 ⇧⌘L / 导出字幕）、播放（播放暂停 / 快退快进 10s ⇧⌘←→ / 倍速 / 截图）、字幕（原文 / 译文 / 双语）
- 控制栏右侧集成播放列表入口；右键菜单含打开文件 / 关闭视频 / 截图 / 导出 / 全屏 / 字幕模式 / 倍速
- 应用内自动更新：下载完成后自动重启替换，minisign 签名校验
- 快捷键：空格暂停、← → ±5s、↑ ↓ 音量、F 全屏、S 截图、E 导出字幕、[ ] 倍速，菜单命令带系统级快捷键（⌘O / ⌘W 等）
- 全新琥珀黄应用图标与欢迎页拖放区
- 平台：macOS（Apple Silicon）可日用；Windows / Linux 播放内核接入中，当前 Release 不提供安装包
